# demos/

Fictional demo tenants used for development, evals and sales (Phase 7).
All names, numbers, addresses and prices are **made up**.

| Folder | Business | Showcases |
|---|---|---|
| `taxmitra/` | CA firm, Kolkata | Bengali/Hindi/English answers, citations, lead capture, booking |
| `cliniccare/` | Family clinic | Receptionist FAQs, booking, after-hours handoff, refusing medical advice |

Each demo has:
- `bot.json` - tenant + bot settings (persona, languages, colours) used by the seed script
- `docs/` - the knowledge-base files uploaded to that bot (mixed formats on purpose)
